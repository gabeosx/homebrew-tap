# Homebrew Tap for Canis97

Install the latest signed and notarized Canis97 release with:

```sh
brew tap gabeosx/tap
brew install --cask canis97
```

Upgrade later with:

```sh
brew upgrade --cask canis97
```

The cask is generated from the canonical [Canis97 GitHub Release](https://github.com/gabeosx/canis97/releases) and updated by the release workflow.
